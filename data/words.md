changes, also reflect them in `src/data/words.js` (or ask Claude to sync them
for you). All words below are **pillam-free** — every letter is a base
consonant carrying the inherent `අ` sound.

## Notes

- Word ordering inside each tier is NOT the order kids see them. The picker
  weights word selection by how much each child struggles with the letters
  inside the word, so words containing weak letters surface more often.
- If you want pillam (කා, ති, etc.) words later, that's a separate tier
  and not part of this build.
